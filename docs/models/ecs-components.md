# Компоненты ECS

Документ перечисляет игровые компоненты и их зоны ответственности.

Связанные документы: [Обзор архитектуры](../architecture/overview.md), [Поток боя игрока](../flows/player-combat-flow.md), [Обработка ошибок](../errors/error-handling.md).

## Роли сущностей
- **Сущность игрока:** идентификатор, transform, ввод, движение, прицеливание, оружие, cooldown, ссылки на рендер.
- **Сущность снаряда:** transform + состояние снаряда.

## Каталог компонентов
- `PlayerTagComponent`: определяет цели систем, принадлежащие игроку.
- `TransformComponent`: связывает ECS-сущность с Unity transform.
- `InputStateComponent`: состояние стрельбы, мировая позиция мыши, вектор движения.
- `AimComponent`: текущее направление прицеливания.
- `MovementComponent`: скорость и опциональная изометрическая проекция осей.
- `RigidbodyComponent`: ссылка на `Rigidbody2D` для физического перемещения.
- `CharacterRenderComponent`: ссылка на `IsometricCharacterRenderer`.
- `WeaponComponent`: визуал оружия/снарядов и боевые параметры.
- `WeaponCooldownComponent`: момент времени следующего разрешенного выстрела.
- `WeaponViewComponent`: runtime-ссылка на transform/renderer визуала оружия.
- `ProjectileComponent`: направление, скорость, время жизни.

## Правила владения данными
- Компоненты хранят изменяемое состояние; поведение выполняют системы.
- Ссылки на Unity-объекты хранятся намеренно для упрощения интеграции.
- Создание сущностей централизовано в bootstrap и системе стрельбы.

Последовательность жизненного цикла см. в [Цикл выполнения](../flows/runtime-loop.md), детали настройки — в [Конфигурация](../config/configuration.md).
