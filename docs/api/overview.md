# API

## Статус
В текущем репозитории отсутствует HTTP/gRPC API-поверхность.

Это Unity gameplay-кодовая база без серверных endpoint-определений, схем валидации запросов и транспортных контрактов.

Связанные документы: [Backend](../backend/overview.md), [База данных](../database/overview.md), [Обработка ошибок](../errors/error-handling.md).

## Практический эквивалент в текущей архитектуре
- Публичными runtime-контрактами фактически выступают поля ECS-компонентов и порядок систем.
- Inspector-поля bootstrap играют роль интерфейса конфигурации игрового поведения.
- Оси Input Manager и состояние мыши формируют интерфейс взаимодействия игрока.

Описание этих runtime-контрактов см. в [Компоненты ECS](../models/ecs-components.md), [Цикл выполнения](../flows/runtime-loop.md) и [Конфигурация](../config/configuration.md).
