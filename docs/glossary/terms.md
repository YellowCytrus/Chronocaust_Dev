# Глоссарий

Связанные документы: [Обзор архитектуры](../architecture/overview.md), [Цикл выполнения](../flows/runtime-loop.md), [Компоненты ECS](../models/ecs-components.md).

- **Кастомный ECS**: реализация entity-component-system на уровне проекта, не пакет Unity DOTS Entities.
- **World**: контейнер, который хранит сущности и выполняет зарегистрированные системы каждый тик.
- **Связность по порядку систем**: зависимость поведения от ручной последовательности регистрации систем.
- **Отложенное удаление**: удаление сущности ставится в очередь и применяется после циклов update/fixed-update.
- **Bootstrap**: MonoBehaviour `EcsCombatBootstrap`, который инициализирует ECS-рантайм.
- **Legacy movement**: `IsometricPlayerMovementController`, предыдущий скрипт движения на префабе игрока.
- **Псевдо-изометрия**: 2D-представление, имитирующее изометрическую перспективу через спрайты/тайлмапы.
- **Inspector wiring**: runtime-ссылки, заданные через сериализованные поля в сценах/префабах.

Для эксплуатационного контекста см. [Конфигурация](../config/configuration.md) и [Обработка ошибок](../errors/error-handling.md).
