# База данных

## Статус
Не применимо для текущего объема репозитория.

В этом Unity-проекте не обнаружены схемы/миграции реляционной или документной базы данных. ORM-модель и миграционные инструменты в исходниках отсутствуют.

Связанные документы: [Backend](../backend/overview.md), [Обзор API](../api/overview.md), [Конфигурация](../config/configuration.md).

## Контекст хранения данных в Unity
- Текущее игровое состояние хранится в памяти как состояние ECS-компонентов в рантайме.
- Постоянный контент хранится как ассеты (сцены, префабы, scriptable-ресурсы).
- Если позже появится персистентность, нужно отдельно документировать границы save/load относительно временного ECS-состояния.

Моделирование runtime-состояния см. в [Компоненты ECS](../models/ecs-components.md) и [Поток боя игрока](../flows/player-combat-flow.md).
