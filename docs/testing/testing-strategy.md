# Стратегия тестирования

Текущее состояние: в `Assets/` не обнаружены runtime-тесты уровня проекта, хотя пакет Unity Test Framework подключен.

Связанные документы: [Обработка ошибок](../errors/error-handling.md), [Поток боя игрока](../flows/player-combat-flow.md), [Сборка и релиз](../deployment/build-release.md).

## Приоритеты тестирования
- **Интеграционные тесты bootstrap**
  - bootstrap присутствует в активной сцене
  - отсутствие обязательных ссылок приводит к быстрому и явному отказу
- **Тесты ECS-потока**
  - ввод обновляет компоненты
  - cooldown выстрелов корректно ограничивает стрельбу
  - время жизни снарядов приводит к корректной очистке
- **Тесты корректности движения**
  - изометрическое преобразование осей дает ожидаемые мировые направления
  - направление анимации соответствует вектору движения

## Рекомендуемые типы тестов
- EditMode: чистая проверка мира/сущностей/систем ECS с mock-компонентами.
- PlayMode: wiring сцен и зависимостей от Unity API (`Camera.main`, `Rigidbody2D`, inspector-поля).

## Quality Gates
- Добавить smoke-test сцену в CI.
- Проваливать сборку, если bootstrap отсутствует в стартовой сцене.

Архитектурные риски см. в [Обзор архитектуры](../architecture/overview.md), prerequisites по настройке — в [Конфигурация](../config/configuration.md).
