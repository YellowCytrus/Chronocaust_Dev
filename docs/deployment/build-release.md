# Сборка и релиз

Документ фиксирует базовые практики сборки и выпуска для текущего Unity-проекта.

Связанные документы: [Конфигурация](../config/configuration.md), [Стратегия тестирования](../testing/testing-strategy.md), [Структура проекта](../architecture/project-structure.md).

## Предусловия сборки
- Версия Unity Editor должна соответствовать проекту (`2020.3.49f1`).
- В Build Settings должна быть выбрана корректная целевая платформа.
- Стартовая сцена должна быть настроена правильно.
- В активной сцене должно быть корректное wiring ECS bootstrap.

## Чеклист сборки
1. Выполнить play-mode sanity-check цикла движения/боя.
2. Проверить отсутствие критичных ошибок в консоли (`EcsCombatBootstrap` missing refs, ошибки камеры/ввода).
3. Собрать целевой player через Unity Build Settings.
4. Проверить поведение на собранной версии (движение, прицеливание, стрельба, очистка снарядов).

## Риски релиза
- Ошибки конфигурации сцен могут тихо отключить ECS-рантайм.
- Предположения про ввод и камеру могут отличаться между платформами.
- Автоматические runtime smoke-тесты пока не обязательны.

Рекомендации по снижению рисков см. в [Обработка ошибок](../errors/error-handling.md) и [Цикл выполнения](../flows/runtime-loop.md).
