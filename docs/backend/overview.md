# Backend

## Статус
Не применимо для текущего объема репозитория.

Этот проект — Unity client/gameplay кодовая база, в которой сейчас нет backend-кода (нет HTTP-сервера, service-слоя, repository-слоя, worker-процессов).

Связанные документы: [Обзор API](../api/overview.md), [Обзор базы данных](../database/overview.md), [Обзор архитектуры](../architecture/overview.md).

## Эквиваленты в текущей Unity-архитектуре
- Оркестрация рантайма выполняется через жизненный цикл Unity и ECS-системы.
- Точки интеграции с внешними сервисами в текущем коде отсутствуют.
- Если backend будет добавлен позже, лучше вводить интерфейсы на границах ECS-систем, а не прямые вызовы в разных системах.

Поведение клиентского рантайма см. в [Цикл выполнения](../flows/runtime-loop.md) и [Конфигурация](../config/configuration.md).
